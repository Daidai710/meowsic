# 手机使用

完整说明见仓库根目录 **[USAGE.md](../USAGE.md)**（推荐从那里开始）。

## 最短路径

1. 电脑已运行 `Start-All.bat`，网页能打开 http://127.0.0.1:8787  
2. 手机下载 [meowsic-v23.apk](https://github.com/Daidai710/meowsic/releases/download/v23/meowsic-v23.apk) 并安装  
3. 与电脑同一 Wi‑Fi → App 内扫码，或填 `http://电脑局域网IP:8787`  
4. **不要**填 `127.0.0.1`  

也可用手机浏览器直接打开电脑网页上的局域网地址（免装 App）。

## 常见问题

| 现象 | 处理 |
|------|------|
| 连不上 | 同一 Wi‑Fi？用了局域网 IP？服务窗口还开着？ |
| 没歌 | 电脑网页是否已扫描本机文件夹？ |
| 防火墙 | 放行 TCP 8787 |
